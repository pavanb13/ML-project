# 🎓 Student Academic Performance Prediction & Early Intervention System

> **IBM BOB College Project — 2024**  
> A machine learning–powered web application that identifies academically at-risk students early and recommends personalised interventions to improve outcomes.

---

## 📌 Project Overview

**SAPPS** (Student Academic Performance Prediction System) analyses 20 student features — spanning academic history, attendance, wellbeing, and socioeconomic background — to:

- Classify each student as **Low Risk**, **Medium Risk**, or **High Risk**
- Predict their expected **GPA** (0.0 – 4.0)
- Generate **personalised intervention recommendations** automatically

## 🚀 Getting Started

### Prerequisites
- Python 3.10 or higher
- pip

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/YOUR_USERNAME/student-ml.git
cd student-ml

# 2. (Optional) Create a virtual environment
python -m venv venv
venv\Scripts\activate        # Windows
# source venv/bin/activate   # macOS / Linux

# 3. Install dependencies
pip install -r requirements.txt

# 4. Run the app
python app.py
```

> **First launch automatically trains all models** (~30 seconds).  
> Open your browser at **http://localhost:5001**

## 🤖 Machine Learning Details

### Dataset
- **2,000 synthetic student records** with 20 features
- Realistic distributions for academic, demographic, and wellbeing attributes
- Auto-generated by `generate_data.py` using NumPy

### Features Used

| Category | Features |
|---|---|
| Academic | `prev_gpa`, `midterm_score`, `assignment_avg`, `quiz_avg`, `lab_score`, `num_failed_before` |
| Engagement | `attendance_pct`, `study_hours_day`, `tutoring_sessions`, `extracurricular` |
| Wellbeing | `mental_health_score`, `sleep_hours`, `part_time_job`, `internet_access` |
| Background | `age`, `gender`, `family_income`, `parent_education`, `first_gen_student`, `distance_km` |

### Models Evaluated (5-fold Stratified Cross-Validation)

| Model | Test Accuracy | CV Mean |
|---|---|---|
| **Gradient Boosting** ⭐ | **83.5%** | 82.9% |
| Random Forest | 81.3% | 82.2% |
| SVM | 75.5% | 76.5% |
| Logistic Regression | 73.3% | 72.1% |
| K-Nearest Neighbours | 62.3% | 64.9% |

**GPA Regressor (Random Forest):** R² = 0.75 · RMSE = 0.34

### Pipeline
```
Raw Features → StandardScaler → Best Classifier → Risk Category
                              → RF Regressor    → Predicted GPA
                                                → Interventions
```

## ⚠️ Ethical Considerations

- Predictions are **decision-support tools only** — final decisions must involve qualified human advisors.
- Socioeconomic features are included to **surface support needs**, not penalise students.
- The model is trained on **synthetic data**; real deployment requires IRB-approved data collection and bias auditing.
- Risk labels should **never be shared with students** without counsellor guidance.
