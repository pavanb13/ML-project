About This Project

IBM BOB College Project — Academic Year 2024

Project Overview

Student Academic Performance Prediction and Early Intervention System (SAPPS) is a machine learning–powered web application designed to identify academically at-risk students at an early stage and recommend targeted interventions to improve their educational outcomes.

The system analyses 20 student features spanning academic history, attendance, wellbeing, and socioeconomic background to classify each student into one of three risk categories: Low Risk, Medium Risk, or High Risk — and simultaneously predicts their expected GPA.

📐 Methodology

  • Dataset: 2 000 synthetic student records with realistic feature distributions
  • Train/Test Split: 80% training, 20% testing (stratified)
  • Cross-Validation: 5-fold stratified CV for unbiased evaluation
  • Models Evaluated: Logistic Regression, Random Forest, Gradient Boosting, SVM, KNN
  • Model Selection: Best classifier by test accuracy, auto-persisted with joblib
  • GPA Regression: Random Forest Regressor evaluated by RMSE and R²
  • Preprocessing: StandardScaler for all numeric features; ordinal encoding for categoricals

🛠 Technology Stack

  • Language: Python 3.12
  • Web Framework: Flask 3.0
  • ML Library: scikit-learn 1.5
  • Data Processing: pandas, NumPy
  • Visualisation: Matplotlib, Seaborn, Chart.js
  • Model Persistence: joblib
  • Frontend: HTML5, CSS3 (custom), Vanilla JS

⚠️ Ethical Considerations

  • Predictions are decision-support tools — final decisions must involve qualified human advisors.
  • Socioeconomic features are included to capture disadvantage and trigger additional support, not penalise students.
  • Model is trained on synthetic data; real deployment would require IRB-approved data collection and bias auditing.
  • Risk labels should never be shared with students without counsellor guidance.
  • Regular retraining is essential to avoid concept drift as student demographics change.
